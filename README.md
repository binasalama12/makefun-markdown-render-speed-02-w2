Streammark is a dependency-free Markdown-to-HTML renderer built around a single forward scan of the source. A cursor walks the input once, dispatching on the characters at each block boundary — fences, headings, quotes, lists, tables, raw HTML blocks — and consuming each construct in place instead of materializing a token tree for the whole document. Blockquotes and list items recurse on just their stripped sub-source, link reference definitions collect into a map as they are met, and a GFM table is recognized by buffering a single paragraph block long enough to test its second line as a delimiter row.

Inline rendering uses a streaming scanner built on the same cursor discipline: escapes, entities, code spans, links, images, autolinks, and hard breaks are all emitted the moment they are recognized, while emphasis is resolved afterwards from the collected delimiter runs with flanking and rule-of-three checks, so intraword cases stay literal when they should. Shared regular expressions live at module level, text is escaped exactly where the output grammar requires it, and nothing outside the Node standard library is ever touched.
